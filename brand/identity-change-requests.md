# Identity change requests — FPT Brand Identity System (package register, since v1.2.1)

The package copy of the platform register (`fpt-platform/docs/identity-change-requests.md`). One line per request: number · title · source · decision and date · status · the release that applied it · what concerns each consumer. Status vocabulary: **APPROVED** (owner / CEO decision recorded) · **APPLIED** (in the named release) · **PROPOSED** (recorded, not applied — nothing is built until the owner decides). The full rule text lives in `README.md`, `components/SPEC.md`, `references/composition-rules.md` (FPT addenda) and `CHANGELOG.md`; the platform-side detail in the platform register. New requests: open an issue in `Fiper-Global/fpt-brand` (README § N).
