## Before any UI work
1. Load `brand/fonts/fonts.css` then `brand/tokens.css` (and `brand/components/components.css` for apps). Tailwind 4 (`@import "tailwindcss"`): map `--fpt-*` in `@theme` or `@config "./brand/tailwind.preset.js"` (README § Install); Tailwind 3: `presets: [require('./brand/tailwind.preset.js')]`.
2. `<html lang="ar" dir="rtl">` by default; English parity via `lang="en" dir="ltr"`. Never one without the other. Six locales exist on the site (EN/AR/FR/ES/PT/TR) — new keys need all six before launch.
3. Design at 390 px first; **375 px minimum**; breakpoints 375 / 390 / 640 / 900 / 1024.
4. Use only `var(--fpt-…)` (`references/tokens-quick.md`; `--fpt-p-*` primitives never directly). A hex literal in app code is a defect (exceptions: e-mail HTML, SVG templates). Never a parent value (`#DC2626`, `#0A0708`).
5. Pick the surface's **pole** before drawing (README § F table): marketing hero = headline, challenge selector = number list, dashboard = number (equity), certificate = headline (paper), statement = number (paper), e-mail = headline + facts card, social = figure or headline, slide = figures.
6. Wiring: the repo's `CLAUDE.md` carries the mandate paragraph (`claude-md-paragraph.md`), `node brand/skill/fpt-brand/verify-skill-wired.mjs` proves it, and `node brand/scripts/verify-identity.mjs src public` runs before every commit.

## Finance semantics — prop firm (binding — `references/finance-semantics.md`)
Equity / balance in `.fpt-figure` (the hero amount: IBM Plex Mono 600, text colour, `USD` as a label) — never red. **CR-01 (APPROVED 31 Oct 2026):** mono only for the hero amount, identifiers / codes / logins and dense financial tables; every amount, date and percentage inside a sentence, list, chip or summary card is in the text font with tabular digits, still one unbreakable `.fpt-unit`. Gain = word «ربح / Profit» + `+` + `--fpt-finance-gain`; loss / drawdown consumed = «خسارة / Loss» + `−` (U+2212) + `--fpt-finance-loss`; drawdown warning (≥ 80 % of a limit) = «تحذير السحب» + `triangle-alert` + `--fpt-finance-drawdown`; breach = «تجاوز الحد» + `circle-x` + `--fpt-state-danger` with the rule named; target reached = success badge; funded = the one brand badge (red fill, white label); pending (activation ≈ 72 h, payout) = `clock` + `--fpt-finance-pending`. Limits always with their base («5 % من رصيد بداية اليوم», «9 % من الرصيد الابتدائي»); split always «حصة المتداول 80 % · حصة الشركة 20 %». Amount + code (`55,312.50 USD`), sign + number + percent (`+10.63 %`), «22 من 31» and date parts are **unbreakable units** (`.fpt-unit`). Currency code on every listing; zero `0.00` is a value, missing is `—` + «لا بيانات». Sample data only from `brand/scripts/sample-data.mjs` (one $50,000 evaluation: 50,000.00 → 55,312.50 USD, +10.63 %, max drawdown −0.81 %, 22 trading days / 30 calendar days; payout cycle profit 3,124.50 USD → trader 2,499.60) — chipped «بيانات تجريبية · SAMPLE», never a claim.

## Anti-AI-tells (binding — `brand/checklists/brand-review.md` § A)
