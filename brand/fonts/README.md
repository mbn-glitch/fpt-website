# brand/fonts

Complete official WOFF2 files (no subsetting / merging), inherited unchanged from fiper-brand v2.0.0: IBM Plex Sans Arabic 400/500/600/700 (APPROVED for all Arabic), Inter 400–700 (body), IBM Plex Mono 400/600 (numbers and code ONLY), Barlow Condensed 600/700/800 (Latin display — decision item 1 default, PROPOSED), IBM Plex Sans 400–700 (shipped, inactive — decision item 1 option C). `fonts.css` declares every face with relative URLs; load it before `tokens.css`. Licences, sources and reserved font names: `licenses/README.md` + the OFL texts.

Not shipped, never load: Cairo (DEPRECATED), JetBrains Mono (DEPRECATED — replaced by IBM Plex Mono), DIN Next LT Arabic (commercial, unlicensed, never loaded by the site either).
