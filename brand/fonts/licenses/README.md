# Font licences — Fiper Brand Identity System

All families are shipped as complete official files converted from the Google Fonts TTF release to WOFF2 (fontTools 4.68, `TTFont.flavor='woff2'`), with no subsetting, merging, renaming or glyph changes. Each family is licensed under the SIL Open Font License 1.1; the full licence text with the copyright line and the Reserved Font Names is in this folder and must travel with the files.
