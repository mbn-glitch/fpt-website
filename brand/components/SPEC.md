# FPT UI components — specification v1.0 (child of fiper-brand v2.0.0 `components/SPEC.md`)

Reference implementation: `components.css` (prefix `.fpt-`), live preview: `preview.html` (AR-RTL ↔ EN-LTR toggle; **dark only** — FPT apps have no light mode; the `.fpt-paper` class is a document/e-mail ground, not a theme). Reference applications: `../mockups/01…08` (AR `index.html` + EN `en.html`), generated by `scripts/build-mockups.mjs` from the one SAMPLE dataset `../scripts/sample-data.mjs`; charts by `../scripts/charts.mjs`.
Requires `fonts/fonts.css` → `tokens.css` → `components.css`. Every colour is a `var(--fpt-*)` token (status in `tokens.json`).

**Inherited unchanged from the parent** (read `/fiper-brand/brand/components/SPEC.md` §§ 1–14 and tables a–f for the full state tables; only FPT deltas are restated here): one dominant element per screen; cards only where they group related information or bound an action; rules instead of boxes elsewhere; red has three roles — the logo tile, the one primary action, the active state — and never emphasises a number; finance semantics are word + sign + colour; labels plain (no slash prefix, no decorative numbering); supporting text ≥ 12 px on phones, **body ≥ 16 px (CR-06, owner 1 Nov 2026 — the five-step app ladder 13 · 16 · 18 · 22 · 32; 13 px for icons, badges, metric labels and the currency code only; ≤ 5 sizes per screen)**; phone gutter 20 px; one primary action per screen; touch targets ≥ 44 px; logical CSS properties; Arabic in IBM Plex Sans Arabic, letter-spacing 0; numbers in IBM Plex Mono, Latin digits, `direction:ltr; unicode-bidi:isolate` (`.fpt-num`); amount+currency, sign+number+percent and date parts are ONE unbreakable unit (`.fpt-unit`, gate `scripts/check-units.mjs`).

**FPT deltas (global)**: brand red `#F42821` (LOCKED) → gradient end `#A30100` (the observed `.gradient-red`, 135deg) is the **only** gradient and the only primary-button fill — white on flat `#F42821` is 4.06:1, so a flat red fill never carries a body-size label (`tokens.json component.button.primary.label-min-size-on-flat-red`); ground `#0A0A0A` / panel `#141414` / elevated `#1A1A1A`; three text tiers (primary `#FFFFFF`, secondary `.78`, muted/label `.55` — the floor, never darker); press scale **.98** (observed); buttons **44 / 48 / 56** px (observed 48/56, sm raised from 40 to the touch floor); **a destructive action is never a filled button** (CR-07, owner 1 Nov 2026 — outline or text + icon; the solid danger fill only inside the final confirmation dialog); the logo is logo v2 (`logos/svg/`): the gradient **tile** as drawn and the white horizontal lockup on dark, never clipped; loss = coral `--fpt-finance-loss`, drawdown warning = amber `--fpt-finance-drawdown`, target = `--fpt-finance-target` (decision item 3); no glass cards, no float / pulse animations, no glow (the site's `.btn-red-glow`, `.glass`, `.animate-float`, `.animate-pulse-dot`, `.radial-red` are observed-only / deprecated).

## 1. Buttons `.fpt-btn` (parent § 1 + deltas)
**Tokens** `--fpt-brand-red` → `--fpt-brand-red-gradient-end` (135deg), `--fpt-c-button-primary-shadow` (= none), `--fpt-c-button-primary-height/-lg/-sm` (48 / 56 / 44), `--fpt-c-button-primary-font-weight` (600 PROPOSED; site 500), `--fpt-space-btn-x` 28 / `btn-lg-x` 36 / `btn-sm-x` 20, `--fpt-motion-press-scale` .98, `--fpt-action-focus-ring` (= brand red, ≥ 3:1 on both grounds).
**Sizes** md 48 px (`h-12` observed), lg 56 px `.fpt-btn--lg` (hero / sticky CTA), sm 44 px `.fpt-btn--sm` (never 40), icon-only 44 × 44, block 100 %.

| Variant | Default | Hover (pointer) | Pressed | Disabled |
|---|---|---|---|---|
| primary | gradient 135deg red → red-deep, white label 600, **no shadow** | gradient shifts to red-deep → deep | scale .98, fill `--fpt-action-primary-pressed` | disabled-bg / disabled-fg |
| secondary | panel fill, `--fpt-line-input` border | border line-strong | scale .98 | same |
| ghost | `white/5` fill, ash border (observed `Button.jsx` ghost) | `white/10` fill, `white/20` border (observed) | scale .98 | same |
| destructive `.fpt-btn--destructive` (outline; **CR-07**) | transparent fill, **danger border + danger label + Lucide icon** — never filled | danger-wash fill | danger-wash fill, scale .98 | same |
| destructive text `.fpt-btn--destructive.fpt-btn--text` | no border, danger label + icon | danger-wash fill | same | same |
| destructive solid `.fpt-btn--destructive-solid` — **inside the final confirmation dialog only** | danger fill `--fpt-c-button-destructive-fill`, bg-coloured label | brightness .92 | same | same |

**Content** verb first, ≤ 3 words, verbatim site keys where they exist: «ابدأ تحدي FPT / Start FPT Challenge» (`hero.ctaPrimary`), «ابدأ التحدي / Start Challenge» (`pricingPreview.cta`), «عرض الخطط / View Plans» (`hero.ctaSecondary`), «تسجيل الدخول / Login» (`nav.login`); PROPOSED: «افتح حسابك الممول / Open your funded account», «عرض الحساب الممول / View funded account», «تحميل الكشف / Download statement», «نسخ / Copy» (credentials).
**Destructive actions (CR-07 — owner decision 1 Nov 2026; inherits fiper-brand v2.3.4, CEO 1 Nov 2026 recommendation B):** delete / cancel / void / reject / disable / close account / sign out = `.fpt-btn--destructive` (outline: transparent fill, danger border + danger label + a Lucide icon — `circle-x`, `x`, `log-out`) or `.fpt-btn--destructive.fpt-btn--text`; hover and pressed = the danger wash `--fpt-c-button-destructive-hover`, **never a fill**. A filled «Cancel» beside the primary reads as a second primary; the one filled red button of a screen is the primary. The **only** filled danger button is `.fpt-btn--destructive-solid` inside the **final confirmation dialog** of that action (`<dialog>`, `role="dialog"` / `"alertdialog"`, `.fpt-modal`, `.fpt-sheet`) when the dialog holds no other primary. The v1.0–v1.1.2 variant (danger wash at rest, solid fill on hover / pressed) is superseded. Tokens: `component.button.destructive.default-style`, `fill-scope`, `hover`, `border`, `label`, `icon`, `fill` (dialog only). Gate: `verify-identity` **DANGER-FILLED-OUTSIDE-DIALOG** (markup, inline style, CSS rules on `.fpt-btn--destructive` including `:hover` / `:active`); `DESTRUCTIVE-WITHOUT-ICON` is reported. Colours unchanged: danger `#E8785A` (decision item 3), never brand red.
**Don't** the site's `hover:scale-[1.02]` grow (observed-only), a gold or black-on-gold button, two primaries, a red button for "delete", a filled danger button outside the confirmation dialog, a destructive button without its icon.

## 4. Rule row `.fpt-rule` · rule bars `.fpt-rulebar` (FPT)
**Purpose** the challenge rules as **rows separated by rules, never boxes** (the site's boxed `KeyRules` grid is a marketing observation, not applied in apps).
**Anatomy** `.fpt-rule`: `__l` label (secondary text, optional 18 px muted icon — no tile) · `__v` value (Inter/Plex Arabic 600, numbers as `.fpt-unit`). 48 px min (`--fpt-c-challenge-rule-row-height`), ash rule under each row, `--strong` opens a block.
**Labels (verbatim keys)** «هدف الربح / Profit Target» (`keyRules.profitTarget`), «الخسارة اليومية القصوى / Daily Drawdown» (`keyRules.dailyDrawdown`), «الخسارة الإجمالية القصوى / Max Drawdown» (`keyRules.maxDrawdown`), «الحد الزمني / Time Limit» (`keyRules.timeLimit`), «الحد الأدنى لأيام التداول / Minimum Trading Days» (`pricingPreview.features.minDays`), «نسبة الأرباح / Profit Split» (`pricingPreview.features.profitSplit`); PROPOSED «المنصة / Platform», «أيام التداول / Trading days», «الصفقات المغلقة / Closed trades».
**Values** `10 %` · `5 %` · `9 %` · `31 يوماً / 31 days` · `5 · قبل أول دفعة 10` · `80/20 ثابتة` · `cTrader` — every number a `.fpt-unit`; percent sign never separated.
**`.fpt-rulebar`** (dashboard): head = rule name + the measured figure vs the limit (`+10.63 % من 10 %`), a 6 px `.fpt-progress`, a state line (icon + word + figure).

## 5. Progress `.fpt-progress--*` (FPT finance semantics on bars)

## 6. Phase stepper `.fpt-phases` / `.fpt-phase` (FPT)

Horizontal on phones (2 columns), each with a 2 px top rule: done = success colour + check · active = brand red (active state) · pending = ash. `__n` (step label + number), `__t` title 16 px 600 (app body, CR-06), `__s` sub (date with Latin digits, or «التفعيل خلال ≈ 72 ساعة»). The marketing variant uses `howItWorks.step2/3` strings verbatim. Don't: three or more phases (FPT is one-phase), icons on the titles.
